# Support & SLA Policy

This repository hosts the Conxian Gateway service and its repository-level governance controls.

## SLA & Support Disclaimer

**No SLA on Public Repositories:** All public repositories in the Conxian organization (`Conxian/*`) operate under standard open-source disclaimers and do **not** provide commercial Service Level Agreements (SLAs), uptime guarantees, or 24/7 incident response. Support is provided on a community-best-effort basis.

**Enterprise & Commercial SLAs:** Binding SLAs (e.g., business-hour response times, integration assistance, and priority patch advisories) are available exclusively under signed commercial B2B contracts for enterprise managed offerings. See [Conxian Business SLA Policy](https://github.com/Conxian/conxian-business/blob/main/docs/SLA_POLICY.md).

## Where to get help

- **General support / governance questions:** open a GitHub issue in this repository using a non-security template or `.github/ISSUE_TEMPLATE/repo_baseline_improvement.yml`.
- **Enterprise / SLA Triage:** open an issue using `.github/ISSUE_TEMPLATE/sla-triage.md` for routing to component maintainers.
- **Gateway bugs or workflow issues:** open a GitHub issue using the bug report template.
- **Policy or process change requests:** open a GitHub issue using the governance request template.

## Security vulnerabilities

Do **not** report vulnerabilities in public issues.

Follow the private reporting process in [SECURITY.md](SECURITY.md) (GitHub private advisories or the security email documented there).
