# Conxian Schemas

Shared domain schemas and JSON-LD type definitions for the Conxian ecosystem.

## Purpose
Ensures consistency of domain objects across the Rust gateway and TypeScript clients. Implements Conxian Job Card Schema (CJCS) v2.0 standards for labor orchestration and institutional settlement.

## Status
**Stable (v0.1.0).** Canonical source for governance, treasury, and audit event structures.

## Usage
Used as a dependency in `@conxian/client-sdk` and `apps/control-plane`.
